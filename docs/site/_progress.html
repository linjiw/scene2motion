What the current method actually does

  1. Scene → native motion controls

    Specify the beam geometry, forward route and a smooth root-height schedule. The tested duck uses a 0.28 m requested dip and quintic entry/recovery ramps; fixed2 and fixed3 change the hold-end time, not the frozen model weights.

  2. Frozen prior → frozen controller

    ARDY generates 208 frames at 25 Hz from the cached WALK prompt and native constraints. Freeze every array, then track it in 32 isolated Isaac environments with SONIC. Paired absent/present arms share references, order and physics seed.

  3. Achieved motion → separate evidence labels

    Check actual beam placement, controller mode and achieved whole-body passage. Save failures, cutoffs, missing suffixes and recovery diagnostics alongside successes. Geometry, contact and motion quality remain different labels.

The proposed compiler is broader than the implemented result. It would qualify the final edited motion and choose a bounded scene-relative correction that preserves both clearance and progress. That improvement is not established yet. The earlier stepping backend used bounded per-frame nonlinear IK over twelve leg joints—not a support QP—and completed 0 / 2 repaired-present local crossings. Neither passing a support proxy nor reference clearance guarantees execution.

A5's operational local passage requires the rear body envelope beyond x = 1.32 m, root beyond x = 1.82 m, upright and inside the corridor for 0.20 s by 4.0 s, with no nominal or 40 mm margin-inflated geometric hazard in that prefix. The beam underside is 1.15 m. This is not a physical-contact-free endpoint or the separate 7.2 m full-route goal. Frozen protocol.

Four of eight fixed3/default groups pass at least three repeats; the descriptive unit-level Wilson 95% interval is 21.5–78.5%. Equal totals are not identical trajectories. A5 analysis and cost.

Contact logging and lower-memory execution

What contact validation establishes

Six corrected simple-body controls passed. Sixty-four G1 operational replays reproduce A5 achieved states, apparatus and modes exactly. The 32 present valid prefixes report zero Table contacts across 30 robot-body filters, but the untrimmed reader reached six points. Excluded-event attribution and a controlled G1 positive-contact probe remain open. Prefix zeros are not episode-level contact freedom.

What the resource optimization establishes

Separate preparation/validation workers and a small resident supervisor avoid keeping model inputs loaded beside Isaac. Compact allocation retained the same 32 slots and exact control replay outcomes. A5 used {{WALL_MIN}} minutes of simulator-process time and peaked at {{PEAK_GIB}} GiB child RSS. This is measured memory use, not an end-to-end speedup or permission to lower resource gates.

The existing 300-record DB preview is geometry/feasibility metadata, not 300 executed demonstrations.
