# A11: body and progress alignment of archived half-step responses

September 6, 2026. Post hoc development diagnostic following failed A10 predictor
readiness. This is an analysis specification, not preregistered confirmation or
authorization to expand the failed inverse model. No generation or simulator launch.

Extract body-primitive signed clearance traces for all 336 native A10 references
and their 336 already executed previews: 48 units, seven commands, all 12 scenes.
The 48 free-WALK controls remain in the source corpus but are outside this native
response diagnostic. Preserve original observation statuses, split groups, inflated
geometry, timestamps, and all archived results. Check every reconstructed scalar
minimum and passage observation against A10 before using the trace.

For each depth/onset/recovery baseline-minus-plus triplet, record the minimizing
body, root position relative to the beam, contact-normal direction and timestamp.
Compare the original scalar midpoint departure with distance to the baseline's
limiting primitive at the baseline's limiting root position. The edited motion
must have exactly one forward crossing bracket, no wider than 0.05 m, and both
distance endpoints must be observed. Interpolate the distance only; never resample
or modify poses. Missing, non-arriving, ambiguous/reversing and undersampled anchors
remain explicitly unavailable. This anchored statistic is descriptive; it does not
replace whole-body clearance or the existing success descriptor.

Report all 48 assignments per axis, available minima/anchor counts, body-switch
counts, event-position shifts, and paired scalar/anchored midpoint departures.
Use scene means and 10,000 scene bootstrap draws (seed 70000) for available paired
differences. Associations cannot establish that switching causes the failure, and
the same-body residual can remain nonlinear. No feature/penalty sweep, new learned
predictor, success relabeling or held-out evaluation belongs to A11.

Deliver a reusable trace measurement with numerical/missingness tests, immutable
source-bound traces, an evidence-backed decision about the next correction, and
an updated plan. Any new native generation needs a separately frozen actual
correction protocol with baseline preservation, the fixed shallower comparator,
equal candidate/preview budgets and final-candidate measurement. Positive G1 contact
sensitivity is a separate open obligation; these MuJoCo pose-distance queries are
not Isaac physics contact forces.
