# Next stage: predict command-induced change before compiling a new duck

**Status: design, not a launched campaign or a performance claim.** September6,2026.
Motivated by the preregistered A7 tie and separate persistence diagnostic. The active
research direction remains execution-aware native duck correction, with frozen
ARDY-G1 and SONIC/default. The three command coordinates and A6 bounds stay fixed.

## Hypothesis and minimal implementation

A7 predicts absolute achieved outcomes and fails to beat initial-preview persistence
on matched numeric targets. Fit the **change caused by the native request** instead:

\[
\widehat y_j(\theta_0+\Delta\theta)
=y_j(\theta_0)+\widehat J_j(z_0)\Delta\theta.
\]

Force zero edit to reproduce the measured initial value exactly. Fit each target's
paired differences using its own observation mask, so clearance need not lose a unit
merely because recovery is censored. All descendants remain in the same scene split.
Use a regularized constant response matrix first, then a single preregistered context
interaction model. Baseline context can use scene geometry and achieved-vs-reference
entry/exit timing; any trace feature must be available from the first preview. No
edited reference/preview may enter the proposer. Prefer physical phase measurements
to adding arbitrary hidden layers or seed/slot identifiers.

Do not force numerical response from a missing initial measurement. For a target
without an observed baseline, return unavailable. Keep a separate all-assigned
arrival/recovery-status head and report correction coverage/refusals. A fallback
proposal for incomplete baselines, if introduced, requires its own declared rule
and exact preview; it cannot borrow a complete unit's admission label. Paired numeric
fits still have conditional-selection limitations and are not a solution to censoring.

## First screen and controls

Reuse A6 development records in a fresh versioned output. Freeze the feature map,
penalty, folds and comparison before computing the successor result. Compare paired
change prediction to (1) zero response, (2) constant pooled response, and (3) the same
scene/reference-only response model. Use outer leave-one-scene-out folds and publish
all assigned failures alongside per-target available pairs. Do not optimize a ranker
over the seven archived commands as the final method.

Primary diagnostics are paired response errors, direction of continuation/exit changes,
and whether proposed bounded corrections change when execution response or progress
constraints are removed. Absolute-outcome MAE is secondary. Require quantitative
evidence against no-change before invoking a constrained optimizer. If robust error
allowances are used for decisions, estimate them inside training folds; an outer
evaluation residual may be reported but cannot tune that fold's proposal.

The A7 generation-expansion gate remains failed. A new CPU screen must motivate a
separate, concrete regeneration pilot protocol; this design does not authorize a
silent retry of A7 with another fitted model or retrospective endpoint change.

## Conditional regeneration pilot

If paired-change prediction is useful, test one small correction from a fixed bounded
grid containing intermediate or compound depth/onset/recovery edits. These are new
native commands, regenerated through ARDY; no trajectory deformation. Declare the
grid, edit cost, error allowances, clearance/deadline/progress constraints and fallback
before generation. All choices must remain within the studied coordinate bounds;
coordinate bounds alone do not establish that compound interactions were measured.

Preserve the two-generation/two-absent-preview contract per arm and the baseline's
runtime encoder slot. A6 baseline reuse is development amortization, not free training
or a claimed generation identity. Charge actual generation batches, simulator padding
and planning wall time separately. The exact regenerated candidate must pass its own
complete preview before it can be selected. No obstacle-present evaluation enters
the decision. Strong scene-aware/reference-quality and budget-matched controls must
receive the same planning opportunities.

Do not open confirmation until this generates a meaningful development gain. Failure
to predict paired change should narrow the claims and stop optimizer expansion. The
controlled positive G1 contact probe and prospective quality endpoint remain separate
necessary work before a contact-qualified final claim; neither is replaced by A7.
